### 1. Постановка задачи
#### Условие задачи
>Напишите программу на Java, которая выполняет следующие действия с двумерным массивом температур:
>1. Считывает с консоли размеры массива N и M, затем элементы массива размером N × M, где каждый элемент представляет температуру в точке с  >координатами (x, y).
>2. Переставляет строки массива в порядке возрастания средней температуры в строке. Если средние температуры равны, сравнивает
> максимальные температуры строк (если равны, сохраняет исходный порядок).
>3. Находит и выводит максимальную температуру и координаты точки, в которой она зафиксирована.
>4. Выводит элементы массива в виде тепловой карты, заменяя температуры на символы, соответствующие их диапазону (например, ‘*’ для низких температур, ‘’ для высоких).
>5. Вычисляет и выводит разницу между максимальной и минимальной температурами в массиве. 

Для решения данной задачи нужно создать массив, в котором будут находиться максимальные значения температур из каждой строки, затем создать массив для средних значений, после чего 
проверяем отсортированость изначального массива, затем меняем строки массива по возрастанию средних значений, в случае равенства этих значений, сравниваем по максимальным значениям в строках, далее выводим искомые значения и тепловую карту температур. 

### Входные и выходные данные 

Данные на вход 

На вход программа получает 2 целых числа: количество строк и столбцов, далее вводятся N × M чисел - значения температур. Ограничим минимальную температуру значением -273,15, соответствующим минимальной возможной температуре -273,15 °C. Максимальное ограничим значением 15 × 10^6 - температура в ядре Солнца.
